# 路线图与已知限制

这里记录可以参与的方向，不代表已承诺的完成日期。

## 近期方向

- 烽火好友筛选在“同时在场”模式下限制最多两位好友，并补前后端测试。
- 对齐可选共享页的时段对象与本地端的 `profit_matches`、`net_profit`。
- 更完善的键盘操作、焦点状态和无障碍回归测试。
- 为新用户改善首次使用和同步失败时的说明。

## 更新与启动

- 启动器异步替换最终失败时，目前只有日志，没有持久修复标记。
- 同版本检查不会主动修复损坏的旧启动器；协议升级前应补齐此机制。
- onefile 启动器可能受冷解包和系统扫描影响，后续评估 native 或 onedir。
- 当前 PE 未统一嵌入 FileVersion / ProductVersion；安装器和应用更新身份另行维护。

## 平台与数据

- 仅支持 Windows 桌面。手机端尚无确认可用的登录桥接方案，普通 H5 不能直接读取小程序登录态。
- 腾讯内部接口和字段可能变化。
- 好友净收益不可计算，因为接口没有提供队友入场成本。
- 全面详情只展示接口实际返回的玩家集合，不宣称完整 64 人记分板。
